# NCM 前驱体结晶数字孪生 (NCM Digital Twin)

## 📖 项目简介

本项目是一个 **完全离线运行** 的 NCM 三元前驱体结晶过程数字孪生工具。它基于工程动力学模型（连续与间歇），通过纯前端技术（HTML/CSS/JS）实现，无需任何后端服务或网络依赖。

该工具旨在辅助化工工艺工程师进行：

- **反应釜共沉淀** 工艺模拟（CSTR/Batch）
- **管道/微反应器** 结晶模拟（PFR）
- 关键指标（过饱和度、粒径分布、成核/生长速率）的趋势分析

## 🚀 核心功能

1.  **反应釜模块**
    - 模拟间歇反应或连续搅拌釜。
    - 实时计算浓度、过饱和度及粒径演变。
    - 支持 pH、温度、搅拌转速等控制参数设定。
2.  **管道反应器模块**
    - 基于平推流（PFR）模型。
    - 支持 **多级加料** 与 **变径** 配置。
    - 可视化沿程的成核与生长速率分布。
3.  **工程化特性**
    - **完全离线**：双击 `index.html` 即可使用。
    - **数据导出**：支持 CSV 格式导出，无缝对接 Excel。
    - **可视化**：内置轻量级 Canvas 图表引擎，无第三方依赖。

## 🛠 使用方法

1.  确保本地已下载所有文件。
2.  使用现代浏览器（Chrome / Edge / Firefox）直接打开 `index.html`。
3.  在左侧面板选择模块（反应釜 或 管道）并输入工艺参数。
4.  点击 **"开始计算"** 查看曲线结果。
5.  点击 **"导出数据"** 保存计算结果。

## ⚠️ 注意事项

- 本工具为工程原型，动力学参数（如 $k_b, k_g$）位于 `js/kinetics.js` 中。
- 实际工业应用时，建议根据实验数据校准 `Kinetics.Params` 对象中的参数。
